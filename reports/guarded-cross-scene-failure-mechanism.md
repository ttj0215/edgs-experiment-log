# C-Guard 跨场景局部退化、视角冲突与空间覆盖归因

指令08，Codex A 实验执行窗口。三个场景的平均留出误差仍低于 B，但同一旧观测的支持方向、留出误差变化和局部空间支撑常常分离。混合旧视角支持同时出现在正、负参考帧，无法单独解释退化。Bonsai 的一个局部点簇迁移后留出误差大多改善，另一个远深度案例则同时出现空间大位移和留出恶化。

## J　可能形成研究贡献的机制假设

**证据可比性与冲突显式化。** 候选生成邻居不同，拟合观测与独立评分观测随候选变化。可研究在共享证据身份下，生成观测的拟合相关性、支持方向不一致和评分集替换如何影响比较置信。单独替换误差范数、比较各候选自身均角或重新组合正深度、FOV 与 confidence，都没有直接解决比较证据身份的问题。经典最优重投影和多视图一致性已有充分先例，贡献须限定于固定候选预算下的比较机制及可验证的消融。[Hartley 与 Sturm](https://perception.inrialpes.fr/Publications/1997/HS97/HartleySturm-cviu97.pdf) · [Schönberger 与 Frahm](https://openaccess.thecvf.com/content_cvpr_2016/html/Schonberger_Structure-From-Motion_Revisited_CVPR_2016_paper.html)

**几何不确定性。** 同时出现深度跳变和小视差的远端案例值得检查射线交会的不确定方向。可以假设同样大小的角误差，在不同视差和深度条件下对应不同的三维位移风险。两场景分层的方向反转限制了将单一视差下限作为接受规则的解释。已有工作讨论视图数、重投影误差和视差与三角化不确定性的关系，潜在贡献需区分于已有不确定性估计，例如检验其是否能解释 EDGS 固定候选之间的排序冲突。[Lee 与 Civera](https://arxiv.org/abs/2008.01258)

**空间支撑独立评价。** 27896 的局部迁移和 ref127 的远点异常说明相同合格点数可对应不同位置、密度及支撑连续性。可以将空间支撑保真作为独立研究问题，在密集初始化预算固定时检验局部点簇是否整体迁移，以及迁移是否与几何证据同向。EDGS 已采用密集初始化，贡献需在空间支撑保持与逐点可靠性之间提供可复现的增量证据。[EDGS 原论文](https://openaccess.thecvf.com/content/CVPR2026/html/Kotovenko_EDGS_Eliminating_Densification_for_Efficient_Convergence_of_3DGS_CVPR_2026_paper.html)

## K　证据边界与下一阶段

建议优先研究可比观测上的冲突、方向性三维不确定性和空间支撑三条互补轴。后续验证若获批准，应预先冻结场景、指标及判定协议，并另行留出未用于本轮归因的观测。当前缓存支持机制假设和反例定位。空间体素、最近邻和留出残差均是代理量，缺少三维真值、独立表面覆盖及渲染评价，相关像素也不构成独立重复。本轮没有从留出结果选择阈值、权重或接受规则。
