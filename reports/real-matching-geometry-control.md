# 真实 RoMa 匹配下的几何修正隔离对照

日期：2026-10-30。任务：科研总控指令 02。状态：**已完成真实匹配和独立对照，未修改正式算法，等待总控审核。**

在 Counter 的固定 3 个训练参考帧、各 3 个邻居、每参考帧 10000 个共同采样下，仅将三角化方程分母列由 clipZ 改为 clipW，便使 **11447 / 30000（38.1567%）** 的 Baseline 最小 pair-error 选择改变。90000 个同索引候选的无 EPS 双视图最大像素 L2 误差中位数从 **1.35314 px 变为 0.128085 px**。这证实几何约定会影响真实匹配的坐标与排名，但不构成独立三维精度、可见性或训练质量改善的证据。

必须同时保留的结果：187 个候选在至少一个生成相机中为非正深度；两条路径各有 11 个最终选择点为负深度且通过原 opacity 误差门槛。候选排名切换造成长尾位置差异，最终所选点最大位移为 154.019 个场景坐标单位。部分候选和分箱的重投影尾部变差，不能只报告总体中位数。

## B. 唯一几何差异与共同误差合约

从现场冻结文件 AST 提取函数到独立命名空间，不导入或构造 Scene/GaussianModel/trainer。所用相机选择、匹配、resize、extract、prepare_tensor、triangulate 函数与冻结 Baseline 的 AST 一致。独立 Corrected 函数由 Original 克隆，只允许以下两处常量变化，并通过反向还原 AST 相等断言：

```diff
- P1_2 = P1[:, :, 2]
+ P1_2 = P1[:, :, 3]
- P2_2 = P2[:, :, 2]
+ P2_2 = P2[:, :, 3]
```

使用行向量约定，F=W_view·P_perspective，clip=X_h F，NDC=(clipX/clipW,clipY/clipW)，clipW=z_cam。对于观测 (u,v)，A 的各行是 `F[:,0]-u*F[:,d]`、`F[:,1]-v*F[:,d]`；Original d=2，Corrected d=3。两者均按原形式求 `A[:,:3] XYZ=-A[:,3]`，使用原 FP32 `prepare_tensor`、CUDA batched `torch.linalg.lstsq`、同样的候选数量和矩阵 batch。

两路径各自重新计算原误差：`e_v=|clipXY/(clipW+1e-4)-observed_NDC|_1`，`E=max(e_ref,e_NN)`；两者均调用冻结 **Baseline** 的 `argmin_NN E`（NumPy 的原 tie/NaN 行为），不调用当前 Unified v2 的可靠性评分。未加入任何有效性过滤、额外权重或 confidence 排序。

独立物理像素误差只作诊断：`p_v=||diag(W_v/2,H_v/2)·(clipXY/clipW-observed_NDC)||_2`，不带 EPS。保存的 FP32 XYZ/F 转为 FP64 做此评估，二维观测来自同一缓存；逐视图及 max(p_ref,p_NN) 分开保存。像素指标不进入 selector 或 opacity。表中像素误差默认指这两个生成视图中的最大值，不是独立验证视图误差。

## G. 结论、局限和供审核的建议

**已经证实：** 当前相机约定下，clipZ/clipW 这一单独因素在同一真实 RoMa 输入上会改变候选三维坐标、原 pair-error、Baseline 最小误差排名以及少量原 opacity 资格。Corrected 的整体生成视图残差更小，但不是每个点/尾部都改善；正式原算法的低误差选择仍可能通过负深度或极远点。

**未得到证据：** 本实验没有独立三维真值、留出训练视图观测、额外 RoMa 验证匹配、正式训练或渲染指标，不能将新旧坐标差称为准确度改善，也不能据此宣称泛化、稳定性提升或多视图可靠性模块有效。3 个参考相机和同图密集点高度相关，分箱与大量像素不是独立随机实验，不作统计显著性主张。

**建议总控审核：** 后续可靠性研究应先明确采用哪一几何约定，并把“几何约定变化”与“可靠性排序变化”分开归因。若批准下一阶段，可基于已保存共同输入设计独立训练视图的验证，以及正深度、近退化与排名长尾的审查；门槛、过滤和训练对照均需另行批准。本次不实施这些建议，不将 Corrected 替换进正式 EDGS，不启动任何训练或新场景。
